# KeiRevision Student Agenda

---

## Features

* **Task & Assignment Tracker:** Keep track of homework, projects, and deadlines.
* **Revision / Study Planner:** Plan out study sessions and revision topics systematically.
* **Timetable Management:** Organize daily or weekly class schedules.
* **Clean & Intuitive Interface:** Designed for quick navigation so you can spend less time organizing and more time studying.

---

## Tech Stack
- Kotlin
- Material Design 3
- XML
- SQL
